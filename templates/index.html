How YOLOv3 Works:

Unlike two-stage detectors (like Faster R-CNN) that propose regions before classifying them, YOLO (You Only Look Once) frames object detection as a single regression problem. It applies a single neural network to the full image, divides it into grid cells, and directly predicts bounding box coordinates and class probabilities simultaneously at 3 different scales (13×13, 26×26, 52×52).
